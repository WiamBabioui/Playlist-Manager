# 🎵 Playlist Manager

A modern and responsive playlist manager built with React and Vite.

## 🚀 Features
- Add, edit and delete tracks
- Drag & drop reordering
- Mini player (play / pause / next / previous)
- Favorites system
- Responsive design (desktop & mobile)

## 🛠️ Tech Stack
- React
- Vite
- CSS (custom responsive design)
